# Frontline (working title)

*A living espionage simulation disguised as a mission-based shooter.*

A browser game by GooseKnight, built for Chromebooks first.

**Milestone 1 — Ghost Training Facility, Yard 7.** Learn to move: sprint, crouch,
vault, climb, use ladders, drop from height, dive and swim.

**▶ Play:** https://gooseknightgaming.github.io/Frontline/

Controls: WASD / arrows to move · mouse to look · Space jump/vault/climb ·
Shift sprint · C crouch/dive · Alt or right-click aim · V first/third person ·
Esc pause (controls can be rebound in the pause menu).
